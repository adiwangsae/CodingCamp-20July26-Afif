# Product Steering — Expense & Budget Visualizer

## What this is
A 5-day Coding Camp MVP assignment: a mobile-friendly personal expense
tracker. Pure client-side (HTML/CSS/vanilla JS), no backend, data lives in
`localStorage`.

## Non-negotiables
- One CSS file in `css/`, one JS file in `js/`.
- No frameworks (React/Vue/etc.).
- Must work on modern Chrome/Firefox/Edge/Safari.
- Keep the UI simple and mobile-first; do not over-engineer.

## Tone
Clean, minimal, dark-mode-first interface with a warm orange accent.
Prioritize clarity and speed over decoration.
